The developer-mode Activity section now shows requests as a ten-column table: time, operation, path, space, host, bytes, took, result, source and copy. It has a header row and a grid layout from 720px wide, measured on the section's own width, and wraps into two lines per request below that. Pause, errors-only and copy-all are included.
